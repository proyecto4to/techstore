# Features

Cada módulo usa las capas `presentation`, `application`, `domain` y `data` cuando son necesarias. Los módulos previstos por el mapa funcional son:

- `auth`, `catalog`, `cart`, `checkout`, `orders`
- `inventory`, `sales`, `purchases`, `cash`, `invoices`
- `shipping`, `notifications`, `chat`, `reports`, `administration`

Las reglas críticas siguen siendo autoridad exclusiva del backend.
