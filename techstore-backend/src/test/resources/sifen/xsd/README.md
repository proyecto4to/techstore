# Esquemas SIFEN v150 usados por las pruebas

Copias descargadas del índice oficial de e-Kuatia el 2026-08-04:
`https://ekuatia.set.gov.py/sifen/xsd/`.

Para que la validación sea reproducible y no use la red, únicamente se cambiaron
los `schemaLocation` HTTP de `siRecepDE_v150.xsd` y `DE_v150.xsd` por rutas
relativas a los mismos archivos oficiales incluidos en esta carpeta. No se
modificaron tipos, restricciones ni catálogos.
